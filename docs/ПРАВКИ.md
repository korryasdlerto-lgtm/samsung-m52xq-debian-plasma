# Правки слоя и пакетов по темам

Только то, что есть в выпуске v1. Файлы — в [rootfs-overlay/](../rootfs-overlay) и [build/](../build).

## Wi-Fi и Bluetooth

| Проблема | Причина | Решение |
|---|---|---|
| Плитка только блокировала радио, прошивка Wi-Fi (WPSS) оставалась включённой | штатная плитка = rfkill | своя плитка → `m52xq-wifi-soft` → `m52xq-wifi-hw`: выгрузка `ath11k_ahb`, остановка WPSS |
| Первое включение — цикл падений `ccpm_mhi.c:397:mhi_issue_request Failed` | чип WCN6750 не сброшен, Wi-Fi стартует во время второй настройки Bluetooth | `m52xq-wpss-restart` ждёт её конца, `m52xq-wl-reset` даёт импульс WL_EN |
| Точка доступа пропала во сне → WPSS падает при пробуждении | WoW без связи | `m52xq-wifi-lost.sh` выгружает ath11k на время сна |
| Bluetooth-колонка отключалась на сон | rfkill перед сном | `m52xq-ufs.sh` не блокирует Bluetooth с подключённым устройством |

## Сон и экран

| Проблема | Решение |
|---|---|
| Экран загорался от сетевых пробуждений | `m52xq-wifi-dark`, `m52xq-wifi-dark.sh` (сокет `wayland-1`) |
| Сорванный сон, телефон не засыпал часами | `m52xq-suspend-guard` повторяет попытку |
| Ползунок яркости не работал | plasmashell ждёт PowerDevil (`10-m52xq-after-powerdevil.conf`) |
| Нет автоповорота после загрузки | сеанс ждёт датчики (`m52xq-sensor-kick`, `m52xq-after-sensors.conf`) |
| Музыка и видео прерывались сном | `m52xq-media-awake` |

## Звонки, SMS, Telegram

| Проблема | Решение |
|---|---|
| Не набирались и не принимались звонки | патч plasma-dialer `0005-m52xq-dual-sim` |
| Окно звонка не выходило вперёд | `m52xq-call-screen-wake` и KWin-скрипты |
| Звонок Telegram не будил экран | поток без имени определяется по клиенту PulseAudio; короткий звук = сообщение, экран не трогается |
| Telegram падал при выключении и включении камеры | правка 8 байт, `build/telegram` |
| Нет звука SMS | пакет `oxygen-sounds`, `m52xq-notify-sound` |
| SIM-менеджер показывал не тот режим | `m52xq-sim-manager`: при одной карте показывается действующий режим |
| Мобильные данные | готовое подключение «Mobile data», плитка переключает автоподключение |

## Камера

| Проблема | Решение |
|---|---|
| Видоискатель боком или вверх ногами | Snapshot: поворот от акселерометра (`0003`), пересчёт после смены камеры (`0004`) |
| Камеры не видны после загрузки | `70-m52xq-udmabuf.rules`, `51-m52xq-cameras.conf`, `52-m52xq-no-v4l2.conf` |
| Камера держала телефон без сна | `m52xq-camera-lock-close` |
| Веб-камеры для Telegram и браузера | `m52xq-virtualcam` |

## Плитки и прочее

- NFC, местоположение, громкая связь, вывод звука, точка доступа; настройки точки доступа и разрешения GPS открываются долгим нажатием.
- `/home` на разделе userdata (`m52xq-home-on-userdata`), снимок экрана кнопками громкости, «Перезагрузка в рекавери».
- Видео в Firefox продолжается в фоне (дополнение Video Background Play Fix ставится политикой).

## Известное

- После чистой установки домашний экран пустой: раскладка привязана к id активити.
- В образе остался `sources.list.d/m52xq-plasma.list` (репозиторий сборки): `apt update` сообщает об ошибке.
- `m52xq-gps-restore` стартует раньше dconf и после загрузки может не включить местоположение.
- `m52xq-app-reaper` работает только в режиме журнала (файл `/etc/m52xq-app-reaper-off`).
