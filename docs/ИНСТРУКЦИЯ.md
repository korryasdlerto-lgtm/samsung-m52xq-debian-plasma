# Debian + Plasma Mobile 6.8.3 на mainline-ядре для Samsung Galaxy M52 5G (m52xq): сборка шаг за шагом

Пошаговая инструкция с командами: от пустой папки до архива для TWRP. Установка готового архива — в [MANUAL-RU.md](MANUAL-RU.md).
Что вошло в выпуск — [CHANGES-v1-RU.md](CHANGES-v1-RU.md), правки по темам — [ПРАВКИ.md](ПРАВКИ.md).

## 0. Что получаем и зачем

- Базовая система: **Debian forky (testing) arm64**, systemd.
- Оболочка: **KDE Plasma Mobile 6.8.3**. В forky — Plasma 6.7.4, но Qt 6.11.2 и KDE Frameworks 6.30.0 там уже подходят для 6.8.3
  (kwin 6.8.3 требует Qt ≥ 6.11.0 и KF6 ≥ 6.30.0), поэтому пересобираются только модули Plasma.
- Железо: тот же слой `m52xq`, что в [Debian Phosh](https://github.com/korryasdlerto-lgtm/samsung-m52xq-debian-phosh): ядро 7.1.13,
  службы и скрипты `m52xq-*`, пересобранные ModemManager, NetworkManager, libcamera, PipeWire, Snapshot, libssc.
- Результат: плоский ext4-образ с меткой `pmOS_root` (его ищет initramfs загрузочного образа) и архив для TWRP.

Порядок: среда сборки (1–3) → Plasma 6.8.3 (4–6) → корень телефона (7–9) → образ и архив (10–12) → проверка (13).

## 1. Что нужно на компьютере

Linux x86_64, около 60 ГБ места, sudo.

```sh
sudo apt install qemu-user-static binfmt-support debootstrap rsync e2fsprogs zip unzip curl git adb
ls /proc/sys/fs/binfmt_misc/ | grep qemu-aarch64        # запуск arm64-программ через qemu включён
```

Нужен свежий `debootstrap` (1.0.145 из Debian: старый не знает forky) и ключи `debian-archive-keyring`. Дальше:

```sh
B=~/m52-plasma; mkdir -p $B/work/src $B/work/fixups; cd $B; R=$B/rootfs-plasma
git clone https://github.com/korryasdlerto-lgtm/samsung-m52xq-debian-plasma repo
```

## 2. Среда сборки: корень arm64

```sh
sudo debootstrap --arch arm64 --foreign --variant=minbase forky rootfs-plasma http://deb.debian.org/debian
sudo cp /usr/bin/qemu-aarch64-static rootfs-plasma/usr/bin/
sudo chroot rootfs-plasma /debootstrap/debootstrap --second-stage

sudo cp repo/rootfs-overlay/etc/apt/sources.list $R/etc/apt/sources.list            # forky main non-free-firmware + deb-src
sudo cp /etc/resolv.conf $R/etc/
for d in dev proc sys; do sudo mount --bind /$d $R/$d; done
sudo chroot $R apt-get update
sudo chroot $R env LC_ALL=C DEBIAN_FRONTEND=noninteractive apt-get -y --no-install-recommends install \
  build-essential devscripts quilt equivs fakeroot dpkg-dev ca-certificates wget xz-utils
```

Проверка: `sudo chroot $R apt-cache policy plasma-mobile kwin-wayland qt6-base-dev libkf6coreaddons-dev` → 6.7.4, 6.7.4, 6.11.2, 6.30.0.

## 3. Ускорение: компилятор без эмуляции (crossdirect)

Под qemu C++ собирается в 5–50 раз дольше. Как в pmbootstrap, вместо эмулируемого компилятора вызывается кросс-компилятор x86_64
той же версии (GCC 16.2):

```sh
sudo debootstrap --arch amd64 --variant=minbase forky native-amd64 http://deb.debian.org/debian
sudo chroot native-amd64 apt-get update
sudo chroot native-amd64 apt-get -y --no-install-recommends install g++-aarch64-linux-gnu gcc-aarch64-linux-gnu binutils-aarch64-linux-gnu

sudo mkdir $R/native; sudo mount --bind native-amd64 $R/native; sudo mount -o remount,bind,ro $R/native
sudo mkdir -p $R/lib64 $R/usr/aarch64-linux-gnu $R/usr/lib/m52xq-cross
sudo ln -s /native/usr/lib/x86_64-linux-gnu/ld-linux-x86-64.so.2 $R/lib64/ld-linux-x86-64.so.2
sudo ln -s /native/usr/aarch64-linux-gnu/lib $R/usr/aarch64-linux-gnu/lib
```

Обёртки компилятора — [build/crossdirect/](../build/crossdirect/README.md). Проверка на программе с Qt6Core: 49 с под qemu → 1 с; код совпадает,
отличается только строка версии GCC.

Подводные камни:

- ссылка на всю папку `usr/aarch64-linux-gnu` ломает эмулируемый gcc (берёт `as` из x86); нужна обычная папка с одной ссылкой `lib`;
- после перезагрузки ПК повторить `mount --bind` (без него модули соберутся под qemu, медленно);
- не монтировать `native` во время идущей сборки: она упадёт с ошибкой 127.

Виртуальный пакет `plasma-version-base-6.8` даёт пакет `plasma-version`:

## 5. Сборка одного модуля

Скрипт [build/scripts/build-mod.sh](../build/scripts/build-mod.sh) делает всё сам: берёт архив 6.8.3 и папку `debian/` от 6.7.4, запускает исправление
упаковки `/root/fixups/<модуль>.sh`, ставит версию `6.8.3-0m52xq1`, выбрасывает патчи Debian, которые уже есть в 6.8.3, ставит
зависимости, собирает и устанавливает пакеты. Тесты и документация выключены (`nocheck nodoc`), `dwz` заменён пустышкой (под qemu он
идёт больше 20 минут на пакет).

```sh
sudo cp repo/build/scripts/build-mod.sh $R/usr/local/bin/m52xq-build-mod; sudo chmod 755 $R/usr/local/bin/m52xq-build-mod
sudo mkdir -p $R/root/fixups $R/usr/lib/m52xq-nodwz; sudo cp repo/build/fixups/*.sh $R/root/fixups/
printf '#!/bin/sh\nexit 0\n' | sudo tee $R/usr/lib/m52xq-nodwz/dwz >/dev/null; sudo chmod 755 $R/usr/lib/m52xq-nodwz/dwz
sudo chroot $R /usr/local/bin/m52xq-build-mod kdecoration      # первый модуль
```

Журналы: `rootfs-plasma/root/build/<модуль>/{builddeps,build,install}.log`.

### Что пришлось исправить в упаковке для 6.8

| Модуль | Причина | Исправление (`build/fixups/`) |
|---|---|---|
| kpipewire | новая библиотека `libKPipeWireMonitor` | добавлена в `libkpipewire6` и `-dev` |
| libkscreen | бэкенд Wayland встроен в `libKF6Screen` | убраны launcher, плагины и служба |
| kglobalacceld | демон теперь внутри kwin | убраны автозапуск и служба |
| libplasma | soname 7 → 8 | пакеты `libplasma8`, `libplasmaquick8`, metatypes |
| breeze | новые `config.kcfg` | добавлены в `.install` |
| kscreenlocker | нет `ksmserver`, новый worker и QML | `.install` |
| kwin | нет `kwin5_update_default_rules`, нет `share/kwin-wayland` | `.install` |
| plasma-union | Debian удаляет `libUnion.so` и заголовки | строки удаления убраны из `debian/rules` |
| plasma-workspace | нет сессии X11 и `krdb`, 13 новых файлов, зависимость `drkonqi` | `.install`, `postinst`, `control` |
| kinfocenter | нужны Qt Graphs и Quick3D | `Build-Depends` |
| plasma-mobile, plasma-nm, plasma-dialer, plasma-keyboard, spacebar | наши патчи | добавляются в `debian/patches` |

## 6. Сборка всей очереди

Порядок важен: `milou`, `plasma-union`, `qqc2-breeze-style` и `plasma-integration` — раньше `plasma-workspace`.

```sh
nohup sh repo/build/scripts/queue.sh > work/queue-run.out 2>&1 &      # переменную B в начале скрипта поправить под свою папку
tail -f work/queue.log
```

Очередь останавливается на первой ошибке, собранное пропускает по строкам `DONE <модуль>` в `work/queue.log`. Пакеты, зависящие от ещё не
собранных модулей, откладываются в `/root/build/deferred.txt` и ставятся в конце. Если остановилось на упаковке (`dh_install`, `dh_missing`),
модуль дособирается без перекомпиляции: исправить `fixups/<модуль>.sh`, применить к дереву и `dpkg-buildpackage -b -uc -us -nc`.
Ошибка GCC «internal compiler error … not reproducible» разовая: повторить.

Наши патчи второй ревизией (`-0m52xq2`), патчи лежат в `/root/pmplasma-patches/<модуль>/`:

```sh
sudo mkdir -p $R/root/pmplasma-patches; sudo cp -r repo/build/patches/* $R/root/pmplasma-patches/
for m in plasma-keyboard plasma-nm spacebar plasma-dialer plasma-mobile; do
  sudo chroot $R env M52XQ_REV=2 /usr/local/bin/m52xq-build-mod $m; done 2>&1 | tee work/rebuild.log
grep 'PATCH FAIL' work/rebuild.log        # наши патчи здесь появиться не должны: скрипт выбрасывает то, что не легло
```

## 7. Пакеты оборудования

ModemManager, NetworkManager, libcamera → PipeWire → Snapshot и m52xq-rawphoto, libssc — папки [build/](../build). Общая схема:

```sh
sudo chroot $R sh -c 'mkdir -p /root/hw && cd /root/hw && apt-get source <пакет> && cd <пакет>-* &&
  cp <патчи> debian/patches/ && ls <патчи> >> debian/patches/series &&
  dch -v <версия>+m52xqN "m52xq" && mk-build-deps -i -r && dpkg-buildpackage -b -uc -us'
```

Точные команды — в `build.sh` каждой папки. Замечания:

- PipeWire пересобирается после libcamera 0.8 (сменились имя библиотеки и свойства камер);
- `dpkg-buildpackage -nc` может пропустить компиляцию: перед повтором удалить `debian/debhelper-build-stamp` и сверить md5 бинарника;
- под qemu не больше `parallel=8`.

## 8. Корень телефона

Основа — корень Debian Phosh (шаги в его репозитории) без Phosh:

```sh
sudo rsync -aHAXx --numeric-ids <rootfs Debian Phosh>/ rootfs-phone/
# локальный репозиторий наших пакетов
sudo chroot $R sh -c 'mkdir -p /root/repo && cp /root/build/*/*.deb /root/repo/ && rm -f /root/repo/*-dbgsym_* && cd /root/repo && dpkg-scanpackages --multiversion . > Packages'
sudo cp -a $R/root/repo rootfs-phone/root/m52xq-plasma-repo
echo 'deb [trusted=yes] file:/root/m52xq-plasma-repo ./' | sudo tee rootfs-phone/etc/apt/sources.list.d/m52xq-plasma.list
sudo cp repo/rootfs-overlay/etc/apt/preferences.d/m52xq-plasma rootfs-phone/etc/apt/preferences.d/
for d in dev proc sys; do sudo mount --bind /$d rootfs-phone/$d; done
sudo chroot rootfs-phone apt-get update
# снять Phosh: сначала симуляция (apt-get -s), удаляться должны только Phosh и приложения GNOME
sudo chroot rootfs-phone sh -c 'apt-mark unhold phosh phosh-common phosh-plugins libphosh-0.45-0 gnome-calls; apt-get -y purge phosh phosh-common \
  phosh-plugins libphosh-0.45-0 phoc phrog phosh-mobile-settings phosh-osk-stevia squeekboard chatty gnome-calls xdg-desktop-portal-phosh \
  gnome-control-center gnome-settings-daemon gnome-console gnome-text-editor gnome-calculator gnome-contacts gnome-weather nautilus'
```

Plasma и приложения (сначала `-s`, удалений быть не должно):

```sh
sudo chroot rootfs-phone apt-get -y --no-install-recommends install plasma-mobile plasma-mobile-tweaks plasma-workspace kwin-wayland kwin-addons \
  plasma-nm plasma-pa powerdevil bluedevil kscreen plasma-dialer spacebar plasma-keyboard systemsettings xdg-desktop-portal-kde \
  qml6-module-org-kde-breeze kde-style-breeze breeze breeze-cursor-theme breeze-wallpaper plasma-integration polkit-kde-agent-1 kde-cli-tools \
  qml6-module-org-kde-milou kinfocenter ksystemstats plasma-widgets-addons plasma-calendar-addons plasma-wallpapers-addons kwrited \
  kde-config-screenlocker plasma-nano ocean-sound-theme plasma-settings qmlkonsole telegram-desktop angelfish \
  qt6-svg-plugins fonts-noto-core fonts-noto-ui-core fonts-noto-mono iw rfkill hostapd dnsmasq-base nftables qml-qt6
```

- без `qt6-svg-plugins` нет значков (SVG), без Noto — шрифтов интерфейса;
- `iw` нужен для Wake-on-WLAN, `rfkill` — для хуков сна, `hostapd`/`dnsmasq-base`/`nftables` — для точки доступа, `qml-qt6` — для окон настроек плиток;
- `kclock` из forky требует `libplasma7`, с 6.8.3 не ставится.

Автовход в Plasma Mobile, `/etc/greetd/config.toml`, одинаково для `initial_session` и `default_session`:

```toml
command = "/usr/lib/aarch64-linux-gnu/libexec/plasma-dbus-run-session-if-needed /usr/bin/startplasmamobile"
user = "user"
```

## 9. Слой m52xq

```sh
sudo rsync -rlp --chown=root:root repo/rootfs-overlay/ rootfs-phone/ --exclude EXCLUDED-FILES.txt
sudo chmod 600 rootfs-phone/etc/NetworkManager/system-connections/*
sudo chmod 440 rootfs-phone/etc/sudoers.d/*; sudo chroot rootfs-phone visudo -c
sudo chroot rootfs-phone systemctl --global enable m52xq-call-screen-wake m52xq-notify-screen-wake m52xq-notify-sound m52xq-media-awake
```

Двоичных файлов в репозитории нет: список с размерами и md5 — [EXCLUDED-FILES.txt](../rootfs-overlay/EXCLUDED-FILES.txt) (модули ядра собираются из
[kernel/](../kernel/README.md), прошивки установщик берёт с телефона). Что делают службы — [MANUAL-RU.md, раздел 10](MANUAL-RU.md).

Особенности Plasma:

- сокет KWin — `wayland-1` (скрипты с `wayland-0` молча не работают);
- сеанс должен ждать датчики: `greetd.service.d/m52xq-after-sensors.conf`, иначе нет автоповорота;
- plasmashell ждёт PowerDevil на шине в `ExecStartPre` (иначе не работает ползунок яркости); `After=`/`Wants=` создаёт цикл, и стола не будет;
- `/etc/fstab` не должен быть пустым (строка `proc` обязательна): initramfs pmOS иначе ждёт раздел `pmOS_boot` и уходит в отладочную консоль.

Telegram с исправлением падения камеры в звонке:

```sh
python3 repo/build/telegram/telegram-desktop-5.7.2-m52xq-camera-patch.py rootfs-phone/usr/bin/telegram-desktop work/telegram-desktop.new
sudo install -m 755 work/telegram-desktop.new rootfs-phone/usr/bin/telegram-desktop; sudo chroot rootfs-phone apt-mark hold telegram-desktop
```

Скрипт правит 8 байт и проверяет md5 исходного и готового файла (только версия 5.7.2+ds-6 arm64).

## 10. Проверка без прошивки: образ как `/data/rootfs.img`

```sh
I=work/rootfs-test.img; truncate -s 7G $I; mkfs.ext4 -q -F -L pmOS_root -O ^metadata_csum_seed $I
mkdir -p work/mnt; sudo mount -o loop $I work/mnt
sudo rsync -aHAX --numeric-ids --exclude=/root/src --exclude='/proc/*' --exclude='/sys/*' --exclude='/dev/*' --exclude='/run/*' --exclude='/tmp/*' \
  --exclude=/usr/bin/qemu-aarch64-static rootfs-phone/ work/mnt/
sudo umount work/mnt; e2fsck -fn $I
adb push $I /data/rootfs.img          # в TWRP
```

Загрузочный образ порта сначала ищет `/data/rootfs.img` и только потом раздел `system`. Откат: переименовать файл в TWRP.

## 11. Образ выпуска

Выпуск v1 снят с проверенного телефона (TWRP, только чтение) и очищен:

```sh
mkdir -p release/mnt-old && cd release
adb exec-out 'dd if=/dev/block/mapper/system bs=4M 2>/dev/null' > system-raw.img
adb exec-out 'cd /data/home/user && tar -cf - .config 2>/dev/null' > home-config.tar
e2fsck -fn system-raw.img
sudo mount -o loop,ro,noload system-raw.img mnt-old
bash ../repo/image/build-release.sh 5400          # МиБ; репозиторий — в ../repo, rootfs-phone — в ..
```

Скрипт копирует корень (без `/root`, `/home`, журналов и кэша apt), кладёт чистый домашний каталог с настройками оболочки, сбрасывает мастер первого запуска,
удаляет подключения, ключи SSH, machine-id, состояние NetworkManager/Bluetooth/SIM, закрытые прошивки и данные датчиков, создаёт `/dev`, ставит слой и
проверяет md5 Telegram.

Размер: занятое + около 200 МБ (установщик дописывает ~112 МБ прошивок). `resize2fs -M` такой образ не сжимает, поэтому ФС сразу создаётся нужного размера.

Проверка на личные данные — до упаковки. Удалённые файлы остаются в свободных блоках, поэтому их затирают и ищут в сыром образе:

```sh
sudo dd if=/dev/zero of=mnt-new/ZEROFILL bs=4M; sudo rm mnt-new/ZEROFILL; sync; sudo umount mnt-new
e2fsck -fn debian-plasma-m52xq-v5-min.img
# patterns: SSID и пароли своих сетей, MAC, серийный номер, номера телефонов, machine-id — по одному в строке
LC_ALL=C grep -aobFi -f patterns debian-plasma-m52xq-v5-min.img        # пусто
```

## 12. Архив для TWRP

```sh
mkdir -p zip/data/rootfs-chunks zip/firmware; cp -r repo/installer/META-INF zip/
cp <boot>.img <vendor_boot>.img <dtbo-frag>.img zip/firmware/          # имена — в начале update-binary; kernel/README.md
S=$(stat -c %s release/debian-plasma-m52xq-v5-min.img)
split -b $((S/2)) -d -a 1 release/debian-plasma-m52xq-v5-min.img zip/data/rootfs-chunks/samsung-m52xq.img.part-
mkdir -p zip/mainline-extras/rootfs-files                                # пустая: слой уже в образе, но запись в архиве нужна
find zip -xtype l                                                        # битых ссылок быть не должно
cd zip && zip -9 -r ../debian-plasma-mobile-m52xq-mainline-v1.zip . && cd .. && unzip -tq debian-plasma-mobile-m52xq-mainline-v1.zip
md5sum debian-plasma-mobile-m52xq-mainline-v1.zip
```

Архивировать изнутри папки: иначе TWRP не найдёт `META-INF`.

## 13. Проверка после установки

```sh
ssh root@172.16.42.1                                # пароль 1111
uname -r; df -h / /home                             # 7.1.13; / около 7,3 ГБ, /home на userdata
dmsetup table                                       # system: все куски раздела (может быть два)
systemctl --failed; mmcli -L; nmcli dev; apt-mark showhold | wc -l
for r in /sys/class/remoteproc/*; do echo $(cat $r/name) $(cat $r/state); done      # modem, adsp, wpss — running
journalctl -k -b | grep -c 'handling crash'         # 0
```

Руками: мастер первого запуска; Wi-Fi плиткой выключить и включить (до 40 с), затем Bluetooth; звонок и SMS с обеих SIM; камера с поворотом и сменой;
звонок Telegram с камерой; сон без кабеля.
